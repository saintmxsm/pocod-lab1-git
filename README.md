# Лабораторная работа №1

Тема: система управления версиями Git и сервис GitHub.

Цель: освоить создание репозитория и сохранение версий файлов.

## Основные команды

- `git init` — создать репозиторий.
- `git status` — проверить состояние.
- `git add` — подготовить изменения.
- `git commit` — сохранить изменения.
- `git push` — отправить коммиты на GitHub.
